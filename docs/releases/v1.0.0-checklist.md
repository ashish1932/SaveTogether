## Release Notes

### V1.0.0 — Initial Release

**Core Features:**
- Society-based bulk service booking with tiered pricing
- Real-time demand aggregation engine
- Razorpay payment integration with webhook verification
- Vendor management and capacity-enforced assignment
- Referral and rewards system
- Admin panel with RBAC, 2FA, and audit logging
- Push notifications via FCM + BullMQ
- Customer support ticket system
- Post-completion review and rating engine
- Executive analytics dashboard
