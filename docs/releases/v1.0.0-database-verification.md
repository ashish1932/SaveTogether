- [x] **Idempotent Seed Pipeline:** Seeding tested against dev & staging schema with safety guards blocking production seeding.

### 2. Tiered Pricing Boundaries (Non-Overlapping)
- [x] **1 – 9 Units:** ₹799/unit
- [x] **10 – 19 Units:** ₹699/unit
- [x] **20 – 39 Units:** ₹599/unit
- [x] **40 – 59 Units:** ₹549/unit
- [x] **60+ Units:** ₹499/unit
- [x] **Boundary Protection:** No quantity overlaps (e.g. quantity 10 matches exact ₹699 tier).

### 3. Demand Campaign Uniqueness & Aggregation
- [x] **Uniqueness Constraint:** Composite key `[societyId, serviceId, serviceDate]` ensures single demand pool per society/service/day.
- [x] **Society Isolation:** Aggregate counts strictly isolated between distinct societies (e.g., ABC Residency vs Green Meadows).

### 4. Historical Price Snapshot Retention
- [x] **Locked Booking Price:** Historical bookings retain `unitPrice` and `totalAmount` locked at booking creation time even when campaign demand unlocks lower tiers.

### 5. Transaction Safety & Concurrency
- [x] **Transactional Atomicity:** Simulated payment failure verifies 100% rollback of demand counter and booking creation.
- [x] **Concurrency Protection:** Simultaneous +1 bookings on initial demand 19 yield exact aggregate 21 without race conditions or lost updates.
- [x] **State Machine Guards:** Invalid transition (e.g., `PENDING_PAYMENT` → `COMPLETED` directly) blocked with 400 error.

### 6. Cascade Deletion Safety
- [x] **Data Retention:** Deleting user or society preserves audit logs, financial transaction ledgers, and payments for compliance and accounting.
